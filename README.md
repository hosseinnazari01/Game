# 🎮 Rock, Paper, Scissors


This is a simple Rock, Paper, Scissors game written in Python.


The player chooses one of three options: Rock, Paper, or Scissors. The computer has a fixed choice: Rock.


The program uses input() to receive the player's choice and if, elif, and else statements to compare the choices.


Game Rules:




🪨 Rock beats Scissors.


📄 Paper beats Rock.


✂️ Scissors beats Paper.


🤝 If both choices are the same, the game is a tie.




Results:




If the player wins, the program prints "You Win!"


If both choices are equal, it prints "It's a Tie!"


Otherwise, the computer wins.




Python Concepts Used:




Variables


User Input


Conditional Statements (if, elif, else)


Comparison Operators (==)


Logical Operator (and)




Goal: Practice Python conditional statements by creating a simple interactive game.
