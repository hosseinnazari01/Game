# 🎮 Rock, Paper, Scissors


This is a simple Rock, Paper, Scissors game written in Python.


The player chooses one of three options: Rock, Paper, or Scissors. The computer has a fixed choice: Rock.


The program uses input() to receive the player's choice and if, elif, and else statements to compare the choices.


Game Rules:




🪨 Rock beats Scissors.


📄 Paper beats Rock.


✂️ Scissors beats Paper.


🤝 If both choices are the same, the game is a tie.




Results:




If the player wins, the program prints "You Win!"


If both choices are equal, it prints "It's a Tie!"


Otherwise, the computer wins.




Python Concepts Used:




Variables


User Input


Conditional Statements (if, elif, else)


Comparison Operators (==)


Logical Operator (and)




Goal: Practice Python conditional statements by creating a simple interactive game.





# 🎮 سنگ، کاغذ، قیچی (Rock, Paper, Scissors)

این یک بازی ساده سنگ، کاغذ، قیچی است که با زبان برنامه‌نویسی پایتون نوشته شده است.

بازیکن یکی از سه گزینه سنگ، کاغذ یا قیچی را انتخاب می‌کند. انتخاب کامپیوتر ثابت است و همیشه سنگ را انتخاب می‌کند.

برنامه از تابع `input()` برای دریافت انتخاب بازیکن و دستورات شرطی `if`، `elif` و `else` برای مقایسه انتخاب‌ها استفاده می‌کند.

## قوانین بازی

🪨 سنگ، قیچی را می‌برد.

📄 کاغذ، سنگ را می‌برد.

✂️ قیچی، کاغذ را می‌برد.

🤝 اگر انتخاب هر دو طرف یکسان باشد، بازی مساوی می‌شود.

## نتایج بازی

اگر بازیکن برنده شود، برنامه پیام `"You Win!"` را نمایش می‌دهد.

اگر انتخاب بازیکن و کامپیوتر یکسان باشد، پیام `"It's a Tie!"` نمایش داده می‌شود.

در غیر این صورت، کامپیوتر برنده خواهد شد.

## مفاهیم پایتون استفاده‌شده

- متغیرها (Variables)
- دریافت ورودی از کاربر (User Input)
- دستورات شرطی (`if`، `elif`، `else`)
- عملگرهای مقایسه‌ای (`==`)
- عملگر منطقی (`and`)
